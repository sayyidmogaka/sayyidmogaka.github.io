# Sayyid Mogaka — Academic Website

Static, responsive academic website for GitHub Pages.

## Publish at https://sayyidmogaka.github.io
1. Sign in to GitHub using the account whose username is `sayyidmogaka`.
2. Create a **public** repository named exactly `sayyidmogaka.github.io`.
3. Upload the contents of this folder into the repository root.
4. Open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

If your account username is not `sayyidmogaka`, rename it first (if the username is available). A repository name by itself does not change the default `username.github.io` address.

## Before publishing
- Replace the portrait placeholder with your photograph.
- Add your CV PDF and replace the CV placeholder in `bio.html` with a link.
- Replace conceptual project diagrams with actual research figures or interactive visualisations.
- Add a public email address and review all biographical and conference details.
